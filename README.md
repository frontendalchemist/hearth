# Hearth

A tool for families coordinating long-term care for someone they love.

My parents are currently taking care of my grandmothers on both sides, and I've witnessed how stressful coordinating their care and also keeping other siblings, family members in the loop about the ones being cared for. There is also a lot of emotional stress of watching your parent go through a decline or just changes in general, dealing with losing freedoms, changes in their bodies, etc. So I wanted to build something that could help take some of the burden off of the main caregivers.

Caregiving for an aging or ill family member is rarely one person's job, but it usually gets organized like it is — in group texts, shared notes, and one person's memory. Hearth is an attempt at something better: a shared place for the appointments, medications, documents, and day-to-day updates that everyone involved needs to see.

**Status:** early and in active development. I'm building it solo and running user research interviews with people currently in a caregiving role. Not yet ready for real use.

## Stack

- **Next.js** (App Router, React Server Components, server actions)
- **TypeScript**
- **PostgreSQL**
