The Family Workspace is where multiple caregivers collaborate on day-to-day
care of the same person. It's the difference between five family members
each keeping notes in their phones and one shared running record.

## What it will cover

- Inviting family members by email; per-recipient role assignment
  (Admin / Coordinator / Viewer)
- Tasks with due dates, priorities, and assignees
- Care log entries with categories (cognitive, medical, physical,
  nutritional, social, financial, behavioral, legal/administrative)
- Per-member alert inboxes — dismissals don't propagate
- Member directory with optional location ("Portland, OR") for
  coordinating in-person help

## Roles at a glance

| Role | Capabilities |
|---|---|
| Admin | Full access; invite/remove members, manage finances, create share links |
| Coordinator | Read/write — upload, edit medications, add tasks, write care-log entries; delete own uploads |
| Viewer | Read-only |
